# Telangana Ground Wells Mapping

Starter Leaflet map for tracking ground wells across Telangana, India.

## Data
- Add point data to `data/Telangana_GroundWells_0.js` as a GeoJSON
  `FeatureCollection`.
- Suggested properties: `well_id`, `district`, `mandal`, `village`,
  `depth_m`, `status`, `owner`, `last_survey`.

## Local preview
- Open `index.html` in a browser or serve the folder with a static server.
